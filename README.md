# enso

ENSO（厄尔尼诺/拉尼娜）状态预测的**核心模型**：纯 Python 标准库实现，零第三方依赖，
约 250 行代码完整覆盖"数据 → 双模型 → 技能加权 → 交叉验证 → 自测"整条预测链路。

## 核心链路

1. **数据**：NOAA CPC ERSST5 Niño 3.4 月距平（官方数据，首次运行自动下载并缓存）；
2. **状态编码**：距平 ≥ +0.5°C 为 El Niño，≤ -0.5°C 为 La Niña，其余中性；
3. **模型 1 状态转移**：以当前状态为条件统计历史上的提前期转移频率，Dirichlet 先验平滑；
4. **模型 2 历史相似型**：近 12 个月轨迹在历史中做高斯核加权近邻检索，加权投票；
5. **组合**：按两模型回测得到的组合技能自适应定权（权重只用起报点之前的数据，无未来泄漏）；
6. **验证**：5 月起报 / 3 个月提前期，逐年留一法交叉验证，与气候态基准对比技能分；
7. **自测**：9 项内置自测（状态边界、概率归一、符号翻转对称、Brier 极值、留一法边界等）。

## 运行

```bash
python enso_core.py             # 输出最新预测（3/6/9/12 个月三态概率）与回测技能
python enso_core.py selftest    # 运行 9 项内置自测
```

依赖：仅 Python 3.8+ 标准库。数据缓存于 `nino34_cache.txt`（离线可用）。

## 说明

- 本仓库是"核心模型"版本：只保留预测主链路，不含 HTML 报告、SVG 图表、
  概率校准、月度分层等外围模块（完整版见 [enso-probability](https://github.com/jiazihong/enso-probability)）；
- 状态阈值 ±0.5°C 为单月口径；业务上 NOAA 官方以 ONI（3 个月滑动平均连续 5 个月）
  判定 ENSO 事件，两者边界月份会有差异；
- 统计模型预报力有限，3 个月内结果参考价值较高，9 个月以上技能快速衰减，
  不可替代动力模式产品。
