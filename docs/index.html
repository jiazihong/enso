2. 各层职责

层做什么关键细节
数据层下载官方月距平并本地缓存首次联网下载，之后离线可用；缺测值跳过
状态编码连续距平 → 三档离散状态≥+0.5 El Niño；≤-0.5 La Niña；其余中性
模型 1 状态转移以当前状态为条件，统计历史提前期转移频率Dirichlet(α=4) 先验平滑，小样本不崩
模型 2 相似型近 12 个月轨迹在历史中找高斯核加权近邻轨迹归一后欧氏距离，加权投票
组合层按两模型过去的技能自适应定权权重只来自起报点之前——杜绝未来泄漏
验证层逐年留一法 + 气候态基准5 月起报 / 3 个月提前期，共 56 年样本外
自测层内置 9 项自测状态边界、概率归一、符号翻转对称、Brier 极值、留一法边界

3. 核心设计原则

  • 严格无未来泄漏：转移统计只遍历起报点之前的样本，组合权重只用历史累计技能，留一法逐年训练。
  • 双模型互补：状态转移捕捉持续性（位相惯性与生命周期），相似型捕捉轨迹形态（事件演变路径），技能加权折衷两者的历史优劣。
  • 概率而非确定性：输出三态概率而非单一判断，Brier 分诚实对照气候态——技能为负的档期不掩盖。
  • 零依赖可复现：仅标准库，任何装有 Python 3.8+ 的机器直接运行；数据与代码分离，离线可用。
